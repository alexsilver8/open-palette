Extend

If it runs in Node, it can be a command.

Write extensions in JavaScript. Each one runs in its own process, so it can't freeze the launcher.

Read the extension docs
index.jspackage.json
// extensions/team-links/index.js
export default {
  commands: {
    'team-links': {
      view() {
        return {
          type: 'list',
          items: links.map((link) => ({
            id: link.url,
            title: link.title,
            icon: { builtin: 'link' },
            actions: [{ type: 'open-url', url: link.url }],
          })),
        };
      },
    },
  },
};
